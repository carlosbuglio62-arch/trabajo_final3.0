Este programa gestiona datos de paises, permitiendo modificaciones de parte
del usuario y brindando estadisticas entre otras funciones. Se parte de  un
conjunto basico de paises (Dataset) que  al  comienzo del  programa  se lee
desde un archivo csv y se  carga en  una  lista de  trabajo, que el usuario 
consultara y/o modificara desde  el menu de opciones, y  cuando  se  decide
salir, se reescribe el archivo base con los datos de la lista actualizada.
